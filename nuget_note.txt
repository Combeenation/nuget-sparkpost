To publish a release:

1. Update the <Version> value in src/SparkPost/SparkPost.csproj.
2. Commit and push the version change to the default branch.
3. In GitHub Actions, run the Publish NuGet Package workflow.

The workflow builds the package and publishes Combeenation.Libs.SparkPost to:

https://nuget.pkg.github.com/Combeenation/index.json
